Appendix A Common generator reference
Import the supplied module from your own program. It generates identical data for all groups, in memory only. Submit
the file unchanged, matching the issued copy byte for byte.
Function Returned Python value
dataset_info() Settings dictionary including planned_readings and nested expected_counts. See the count
reference in 2.2.
meter_metadata() List of 4,000 dictionaries with the five meters columns defined in 1.2.
iter_readings() Iterator of eight-field reading dictionaries as defined in 1.2. Each call restarts the dataset.
Consume progressively.
anomaly_events() List of 40 dictionaries with meter_id, start_time, end_time, and event_type.
Meter IDs run from 1000000000 to 1000003999. Region 1 through Region 10 each have 400 meters. Customer types
are residential, commercial, and industrial. power_factor is 0.95. Timestamps use ISO text with +02:00. Event starts are
inclusive and ends exclusive.
Readings arrive from the iterator in event_time order, not received_time order. Duplicate copies match in all eight
fields. Interval meanings and units are defined in 1.2. No seed or settings changes are required.
